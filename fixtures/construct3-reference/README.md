# Construct 3 reference fixtures

This corpus records semantic and structural cases observed in two real C3
folder projects stored in the GitHub repository
[MrPrattASH/Game_Design_In_Construct_3](https://github.com/MrPrattASH/Game_Design_In_Construct_3).

Pinned source revision:
`0dfcecbeda166a10c9d621f655c21e51dcf89020`

- Platform abstraction:
  `LG1_Using_Construct3/module_2.0_basic_platformer/finished_construct_folder`
- Driving template:
  `Bonus_Learning_Material/module_1_Advanced_AI_Driving_Cars/finished_example_construct_folder`

The fixture catalogue contains metadata and expected behavior only. It does
not copy project art, audio, fonts or full source assets. It also does not make
Construct's undocumented file format a stable public schema.

Use these fixtures to test the built-in C3-to-Impossible importer. Folder
projects and `.c3p` archives must enter the same virtual-source reader and
produce equivalent normalized Impossible projects.

See [CONSTRUCT3-PROJECT-STUDY.md](../../docs/CONSTRUCT3-PROJECT-STUDY.md) for
the full research and importer design.
